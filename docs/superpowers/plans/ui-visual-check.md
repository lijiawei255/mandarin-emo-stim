# UI 视觉核验记录（暖奶油主题）

日期：2026-09-10 · 主题提交：`feat(ui): 暖奶油主题`
截图：`docs/images/ui/{1280x720,1440x900,1920x1080}_{idle,analyzed,loading}.png`
（Windows 11，125% DPI 缩放，真实平台渲染；1920×1080 受屏幕物理尺寸限制实际为 1924×1055）

## 三层验证结果

### 第 1 层：几何自动检查（`scripts/ui_geometry_check.py`，offscreen）

9 组（3 分辨率 × 3 状态）全部 **OK**，并已作为 `tests/test_gui_layout.py` 进入 `-m slow` 测试集。

首次运行发现并修正的问题：

| 发现 | 根因 | 修正 |
|------|------|------|
| 模态数值标签 `squeeze`（需 52px，仅 40px） | 写死 `setFixedWidth(40)`，不同字体下 "0.00" 宽度差异达 30% | 改为 `fontMetrics().horizontalAdvance("0.00") + 10` |
| 模态名称标签同上 | `setFixedWidth(72)` | 按 "四个汉字" 度量 |
| ASR 文本框 `too_short`（需 78px，仅 72px） | 固定像素高度低于样式表 padding 计入后的最小提示高度 | 改为按行距的最小/最大高度区间 |
| 进度条 `too_short` 误报 | 文字隐藏的细线进度条，minimumSizeHint 仍含文字高 | 检查器对 `isTextVisible()==False` 的进度条跳过该项 |

### 第 2 层：真实渲染截图目视（本人逐张检查）

发现并修正：

- **主按钮文字消失**（analyzed 状态）：`QFrame#StimulusPanel QWidget { background: transparent }` 的特异度高于 `QPushButton#btn_generate`，把主按钮底色打成透明，白字落在白卡片上不可见。改为只对 `QLabel` 与复合容器（`MetricBar`/`ModalBars`/`WaveformView`/`QSlider`）设透明。
- 主按钮禁用态白字落在 `accent_soft` 上几乎不可读 → 改用 `text_faint`。

### 第 3 层：视觉模型第二意见（qwen3-vl-plus，`detail=high`）

对每条意见按截图与实测对比度逐一核实，**采纳 4 条，驳回 8 条**：

| VLM 意见 | 核实 | 处置 |
|----------|------|------|
| 警告色 `#B8860B` 在浅底上对比度不足 | 实测 3.0:1（card_alt），低于 AA | **采纳**：warning → `#8A6200`（4.7:1） |
| 进行中/象限标题用 accent 作文字色对比度不足 | 实测 `#D97757` 3.1:1、`#C4633F` 4.0:1 | **采纳**：新增 `accent_text #A8502E`（5.5:1）专用于文字 |
| 「已录制」success 色偏淡 | 实测 `#788C5D` 3.6:1 | **采纳**：success → `#56703F`（≥4.4:1） |
| `[叹息 0.72]` 与上一行间距过小 | 目视确认偏紧 | **采纳**：padding-top 4 → 10px |
| 「音量」二字左半被遮挡 | 截图中完整可见 | 驳回（幻觉） |
| 播放/暂停等按钮高度与主按钮不一致 | 同一 QSS 规则，实测同高 | 驳回 |
| 右列与窗口右缘留白 >300px | 三栏按 1:3:2 铺满，右缘贴边 | 驳回 |
| 「(无副语言事件)」被右缘裁切 | 完整可见，几何检查无 overflow | 驳回 |
| 音量滑块轨道溢出面板 3px | 几何检查无 overflow | 驳回 |
| 时间轴刻度 "10" 溢出 1–2px | pyqtgraph 轴标签居中于刻度，属绘图库常规行为 | 驳回 |
| 模态数值列未严格右对齐（差 1–2px） | 同一固定列宽右对齐，像素级检查一致 | 驳回 |
| 修正后仍称 `[叹息 0.72]` 为浅灰 `#A0A090` | 实际色值 `#8A6200`，5.5:1 | 驳回（识别错误） |

修正后对 1440×900 分析态做事实性复核（6 项是/否），VLM 全部回答符合预期，结论「通过」。

## 已知限制

- offscreen 平台无 CJK 字体回退，中文渲染为方块；几何检查不受影响（字宽度量仍有效），但目视核验必须在真实平台运行 `scripts/gui_screenshot.py`。
- 视觉模型作为独立第二意见有价值（4 条真问题均被其指出），但幻觉率高，结论不能直接采信，必须逐条核实。
