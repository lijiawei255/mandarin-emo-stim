# 用户使用手册

## 1. 启动

### GUI 模式（推荐）

```bash
conda activate mandarin-emo-stim
python main.py
```

首次启动会自动检测硬件、检查并下载模型（约 6GB，国内网络走 ModelScope + hf-mirror.com），完成后进入就绪状态。

### 无头模式（分析单个音频文件，不启动 GUI）

```bash
python main.py --headless path/to/audio.wav
# 或
python -m src.cli --audio path/to/audio.wav --out stim.wav
```

## 2. 界面操作

界面为暖奶油色主题（ivory 底色、陶土橙强调），分五个区域：

| 区域 | 功能 |
|------|------|
| 左侧「音频输入」 | 开始录音 / 上传音频 / 停止重置、麦克风选择、录制计时、SNR 与模态降级警告 |
| 中部「核心指标」 | NEGATIVE / VALENCE / AROUSAL 三条指标、情绪象限、ASR 转写文本 |
| 右侧「多模态分解」 | 6 模态分项条形图 + 副语言事件 |
| 底部「声刺激」 | 生成 / 播放 / 暂停 / 停止 / 保存、波形与参数、音量 |
| 底栏状态 | 运行状态、推理模式、模型加载进度 |

界面截图见 `docs/images/ui/`。

### 操作流程

1. **输入音频**（两种方式）：
   - **实时录音**：点击「开始录音」开始采集（实时显示已录制秒数，上限 60 秒），再次点击「停止录音」结束，自动落盘并触发分析。可在下拉框选择麦克风设备。
   - **上传音频**：点击「上传音频」选择 WAV/MP3/FLAC 文件。
2. **自动分析**：系统自动执行 VAD → ASR → 6 模态特征 → 加权融合。
3. **查看结果**：中部显示三大指标与象限，右侧显示各模态贡献。
4. **生成刺激**：点击「生成刺激波形」，根据当前情绪合成差异化声刺激。
5. **播放/保存**：▶ 播放 / ⏸ 暂停 / ■ 停止 / 💾 保存 WAV。

### 受试者档案与个人基线（v0.4，推荐流程）

每个人的嗓音在平静状态下各模态的分数并不都落在 0.5，会造成系统性偏移；用受试者**自己**的
平静朗读做基线，在交叉验证中是最稳的配置。基线**可以预存**：受试者来做实验时往往已不平静，
建议在另一个平静的场合先录好基线，实验当天只需选用。

1. **预录基线**（平静场合）：「文件 → 为受试者录制基线（30 秒平静朗读）…」，输入受试者编号
   （如 S01），按提示用日常平静语气朗读任意文字约 30 秒，到时自动停止。同一编号可多次录制，
   系统取平均以降低单次抽样误差。也可「从音频文件添加受试者基线…」导入已有录音。
2. **实验当天**：在左侧「受试者档案」下拉框选中该受试者，之后的分析用其基线替代语料级校准，
   象限标题下会显示「个人基线校准（档案 S01）」。选「无」即回到语料级校准。
3. 基线应在与实际使用相同的设备与环境下录制；更换麦克风或环境请重新录制。「删除当前受试者档案」
   可移除档案。命令行：`--profile S01` 选用，`--profile S01 --calibrate-user --audio calm.wav` 添加录音，
   `--list-profiles` 列出。

档案文件在 `portable_data/calibration/profiles/`，属受试者数据，请勿提交到仓库。

### 结果里的「可信度」与「模态分歧」

象限标题下会显示「可信度高/中/低（该档实测准确率 y）」与「模态分歧 ±x / ±y」。分歧是六个模态
对负面分与唤醒度的分歧程度（加权标准差）；注意实测中**分歧小并不代表可信**（各模态都接近中性时
也算一致，但那是证据弱），可信度等级来自评测语料上各分歧档的实测准确率，请以等级和括号里的
数字为准。

## 3. 三大核心指标

| 指标 | 含义 | 范围 |
|------|------|------|
| **Negative Score** | 综合负面分，0=极度正面，1=极度负面 | [0,1] |
| **Valence** | 效价 = 1 − Negative，0=负面，1=正面 | [0,1] |
| **Arousal** | 唤醒度，0=平静/低落，1=激动/兴奋 | [0,1] |

## 4. 情绪象限

基于 Russell 情绪环模型：

| 象限 | Valence | Arousal | 含义 |
|------|---------|---------|------|
| Q1 | 高 | 高 | 积极/兴奋 |
| Q2 | 低 | 高 | 焦虑/紧张 |
| Q3 | 低 | 低 | 低落/抑郁 |
| Q4 | 高 | 低 | 放松/满足 |

不同象限会生成不同参数的声刺激（基频、脉冲率、响度、谐和结构等）。

## 5. 声音安全

- 生成音频的**数字峰值限幅**为 -10 dBFS，响度按 RMS 归一到 [-30, -10] dBFS。**dBFS 是数字满刻度相对值，实际声压级取决于你的播放设备与系统音量，本软件无法保证任何 SPL 数值。**
- 请从低音量起听并逐步调到舒适水平；如需严格的声压控制，请用声级计对播放链路做校准。
- 建议使用耳机获得最佳体验（非必须，扬声器同样安全）。
- **特殊人群**（癫痫史、严重心脏病、重度抑郁症正在接受治疗者）建议在专业人员指导下使用。
- 本工具为科研探索用途，**不构成医疗建议或治疗手段**。

## 6. 历史记录

每次分析结果自动存入 SQLite 数据库（`portable_data/history/records.db`）。

- 上限 **200 条**，满额时会弹窗引导导出并清空。
- 通过「文件 → 导出历史记录」可导出 JSON 或 CSV（UTF-8-BOM，Excel 友好）。
